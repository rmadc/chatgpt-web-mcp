# Local execution policy
- Ask the user before delegating work to another model, including via this MCP.
- Explain scope, material sent, reason and estimated cost before substantial work.
- No subagents, automatic account rotation, extra probes, or unapproved live messages.
- Default GPT-6.1 Sol Light for Work and Medium for Chat; fail if unavailable.
- Preserve local archives; retrieve selected excerpts rather than reinjecting full history.
- Keep documentation and verification bounded. Stop before unexpected troubleshooting.
